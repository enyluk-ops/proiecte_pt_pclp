
# Ghicește numărul 🎯

**Joacă online:** [Deschide jocul](https://superguess.streamlit.app/)

Un joc realizat în Python, cu Streamlit, în care trebuie să ghicești un număr între 1 și 20 în maximum 7 încercări.

## Cum rulezi local

1. Instalează dependențele:

   `pip install -r requirements.txt`

2. Pornește aplicația:

   `streamlit run app.py`
